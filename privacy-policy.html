سياسة الخصوصية – Style Roj

آخر تحديث: 30 سبتمبر 2026

نحترم خصوصية مستخدمي Style Roj ونلتزم بالتعامل مع المعلومات الشخصية التي يقدّمها المستخدم من خلال الموقع والتطبيق بطريقة مناسبة لغرض تشغيل الخدمة وتحسين تجربة الاستخدام.

المعلومات التي قد نجمعها

قد نجمع المعلومات التي يقدّمها المستخدم عند إنشاء الحساب أو استخدام الخدمة، مثل:

  • الاسم.
  • عنوان البريد الإلكتروني.
  • بيانات الحساب وتسجيل الدخول.
  • بيانات الطلبات والمقاسات أو التفاصيل التي يرسلها المستخدم عند طلب التفصيل.
  • معلومات مرتبطة باستخدام الموقع، مثل بيانات الزيارة المرتبطة بالحساب عند توفرها.

كيف نستخدم المعلومات

  • إنشاء وإدارة حساب المستخدم.
  • معالجة الطلبات ومتابعتها.
  • التواصل مع المستخدم بخصوص الطلبات والخدمات.
  • تحسين أداء الموقع والتطبيق وتجربة المستخدم.
  • حماية الخدمة ومنع الاستخدام غير المصرح به.

الخدمات الخارجية

يستخدم Style Roj خدمات خارجية لتشغيل بعض وظائف الموقع والتطبيق، ومنها Appwrite لإدارة الحسابات والبيانات، وقد يستخدم تسجيل الدخول عبر Google عندما يختار المستخدم ذلك. كما قد يتم توجيه المستخدم إلى WhatsApp لإتمام التواصل أو إرسال تفاصيل الطلب.

حماية المعلومات

نتخذ إجراءات تقنية وتنظيمية مناسبة للمساعدة في حماية المعلومات من الوصول أو الاستخدام غير المصرح به. ومع ذلك، لا يمكن ضمان أمان أي خدمة على الإنترنت بشكل مطلق.

مشاركة المعلومات

لا نبيع المعلومات الشخصية للمستخدمين. قد تتم مشاركة المعلومات فقط عندما يكون ذلك ضرورياً لتشغيل الخدمة أو تنفيذ الطلب أو عندما يطلب المستخدم ذلك، أو عندما يكون الإفصاح مطلوباً بموجب القانون.

الاحتفاظ بالمعلومات

نحتفظ بالمعلومات طالما كانت لازمة لتشغيل الحساب والخدمات والطلبات، أو للمدة المطلوبة لأغراض تشغيلية أو قانونية مناسبة.

حقوق المستخدم

يمكن للمستخدم التواصل معنا لطلب المساعدة بخصوص حسابه أو بياناته، بما في ذلك طلب تصحيح المعلومات أو حذفها عندما يكون ذلك ممكناً وفقاً لاحتياجات تشغيل الخدمة والالتزامات القانونية.

التواصل

للاستفسارات المتعلقة بالخصوصية، يمكن التواصل مع Style Roj عبر قنوات التواصل الرسمية المتاحة على الموقع.

هذه الصفحة نموذج سياسة خصوصية عامة للاستخدام مع الموقع والتطبيق، وقد تحتاج إلى تعديلها حسب طريقة تشغيل الخدمة والقوانين المطبقة عليك.
